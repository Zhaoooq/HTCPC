# CPC_1 结构说明

这是从 `CPC_Control_System` 拆分出的模块化版本，原目录未改动。

## 目录职责

- `main.cpp`: 程序入口、硬件生命周期、信号连接、退出清理。
- `hardware/`: GPIO/PWM/PT100/MAX31865、N4IOA01 比例阀等硬件访问封装和引脚表。
- `control/`: 温控 PID 算法。
- `algorithms/`: OPC 原始信号计数、阈值、峰识别和浓度计算辅助。
- `ui/`: Qt 页面构建、公共控件、绘图初始化、格式化显示、水印。
- `state/`: 运行状态结构体，后续可继续扩展为更完整的状态管理层。
- `daq_worker.h`: FTDI/ADS8688 采集线程，沿用原有实现。
- `LiquidControlSystem.*`: 液位和补排液控制，沿用原有实现。
- `qcustomplot.*`: 绘图库，沿用原有文件。

```bash
cd /home/pi/Desktop/CPC_1

```

## 比例阀控制

- 树莓派串口：`/dev/ttyAMA0`，`9600-8N1`。
- N4IOA01 模块地址：`0x01`，通道 1 电流寄存器：`0x0000`。
- 界面入口：`气路` -> `比例阀开度控制 (N4IOA01)`。
- 开度映射：`0% = 4.00 mA`，`50% = 12.00 mA`，`100% = 20.00 mA`。
- 点击“设置开度”后才会发送新设定；“读取输出”读取模块当前电流；“安全关闭”写入 `4.00 mA`。
- 程序正常退出时会再次尝试写入 `4.00 mA`，然后关闭串口。

### 目标压差闭环

- 在“气路”页选择 A0/A1/A2 作为反馈，填写目标压差，并先启动气泵，再点击“启动压差闭环”。闭环不会随程序启动而自动开启。
- 默认 PI 参数为 `Kp=0.40`、`Ki=0.08 1/s`；误差按所选传感器满量程归一化，单次最多改变 `5%` 开度，目标附近使用 `0.2% FS` 死区。参数需要根据实际气路从较小值开始整定。
- “开度增大，压差增大/减小”必须按比例阀在实际气路中的作用方向选择；方向选反会使控制量背离目标。
- 启动闭环时以当前手动开度作为初始输出。闭环运行期间手动设置被锁定，但“安全关闭”始终可用。
- 压差反馈超过 `1.5 s` 未更新、传感器报警/通信失败、比例阀通信失败、气泵停止或用户停止闭环时，程序会退出闭环并尝试输出 `4.00 mA`。

运行程序的用户需要拥有 `/dev/ttyAMA0` 的读写权限，且该串口不能同时被串口控制台或其他程序占用。

## ADS1115 三路压差测量

- ADS1115 使用 `/dev/i2c-1`、地址 `0x48`、`±4.096 V` 增益和 `128 SPS`，以单次转换模式轮询三个输入通道。
- A0 接 `0~40 kPa` 压差传感器，换算系数为 `8000 Pa/V`。
- A1 接 `0~500 Pa` 压差传感器，换算系数为 `100 Pa/V`。
- A2 接 `0~300 Pa` 压差传感器，换算系数为 `60 Pa/V`。
- 三只传感器均为 `0~5 V` 输出，并分别经过相同的 `10 kΩ / 18 kΩ` 分压后接入 ADS1115；软件会反算各路传感器原始电压。
- 程序启动后自动对三路进行 3 秒零点校准。校准期间气泵启动按钮会被禁用，所有传感器的 H/L 两侧必须等压。
- 界面入口为 `气路`，分别显示“40kPa压差传感器”“500Pa压差传感器”和“300Pa压差传感器”；可查看压差、ADC 电压、传感器电压和满量程百分比。
- “三路压差传感器重新零点校准”按钮会同时重置三路零点，操作时若气泵正在运行，程序会先关闭气泵。
- 每一路独立使用 9 点中值滤波和系数 `0.20` 的指数滑动平均；接近 ADC 输入上限、超出对应量程或 H/L 可能接反时，界面会显示红色警告。

系统需要启用 I²C（`/boot/firmware/config.txt` 中包含 `dtparam=i2c_arm=on`），并能通过 `i2cdetect -y 1` 在 `0x48` 看到 ADS1115。

## 旁路流量模式

- 原“整机风扇1”接口现接旁路电磁阀，使用 BCM GPIO24（物理针脚 18）。
- 由操作人员在界面中手动选择工况，程序不自动切换流量模式。
- GPIO24 高电平打开旁路阀，对应 `1.5 L/min` 大流量模式。
- GPIO24 低电平关闭旁路阀，对应 `0.3 L/min` 小流量模式；程序启动、正常退出和 GPIO 释放时均保持该默认状态。
- 模式切换成功后，颗粒数浓度换算会同步使用 `1500 ml/min` 或 `300 ml/min` 的当前流量。

## 自动补液

- 液位传感器使用 GPIO27：高电平表示液位正常，低电平表示缺液。
- 连续两次检测到缺液后，GPIO22 输出高电平，打开进液电磁阀。
- 液位恢复高电平时立即把 GPIO22 拉低，关闭进液电磁阀。
- 单次补液最长 10 秒；超时后关闭并锁定进液阀，液位恢复正常或重新启动监控后解除锁定。
- 传感器读取或阀门写入失败时采用安全关闭策略，不会把读取错误当成缺液。
